# `@agentic-design-kit/react`

Runnable React components for core Agentic Design Kit patterns.

## Exports

| Component | Pattern ID |
|-----------|------------|
| `CopilotInput` | `copilot-input` |
| `MandateApprovalCard` | `mandate-approval-card` |
| `StreamingThoughtState` | `streaming-thought-state` |
| `DualSpeedLayout` | `dual-speed-layout` |
| `SuggestionRail` | `suggestions` |
| `ClarifyBeforeAct` | `clarify-before-act` |

Specs / denser docs: `../../patterns/<id>/README.md`.

## Usage

```tsx
import { MandateApprovalCard } from "@agentic-design-kit/react";
import "@agentic-design-kit/react/styles.css";
```

Demo: from repo root `npm run demo`.
